# Privacy and retention

Default local storage is project-scoped and private. Traces and tool outputs are redacted before persistence; providers receive only the context selected by policy. Memory records may carry an explicit `expiresAt`; `POST /api/v1/memory/prune-expired` removes only expired records the actor can write, with a bounded namespace filter and audit count. Read-time policy retention remains separate because agents can have different windows; the prune route never guesses a deletion deadline from one agent's policy. Configure retention by namespace, expire stale memories, and honor export/deletion across relational, object, vector, and audit stores. Audit evidence may require a separate legally approved retention schedule.
