# Evaluation guide

Use computational sensors (schemas, tests, typechecks, policies, invariants, citation checks) and inferential sensors (quality, research, security, independent reviewer). The API registers datasets and cases, and `POST /api/v1/evaluations/runs` executes deterministic `exact-match` and `contains` graders against caller-supplied case outputs, persists pass/fail scores and bounded evidence, and never stores the raw outputs. Unsupported graders fail explicitly instead of being treated as passes. Keep the generating agent separate from the evaluator; model-based judges remain an external adapter that must provide its own contract tests. Store grader evidence, model/version, intermediate steps, and replay links. A release is blocked by regression failures or missing verification evidence.
